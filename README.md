# Hệ Thống Quản Lý Mượn Thiết Bị Phòng Học

Dự án phát triển hệ thống web quản lý mượn/trả thiết bị phòng học, giúp tối ưu hóa quy trình mượn thiết bị cho sinh viên và hỗ trợ quản trị viên kiểm soát tình trạng tài sả 

## 🚀 Công nghệ sử dụng
* **Frontend:** HTML, CSS, JavaScript (Fetch API).
* **Backend:** PHP (Sử dụng Session để xác thực, Prepared Statements chống SQL Injection).
* **Database:** MySQL.
* **Môi trường phát triển:** XAMPP.

## ✨ Chức năng chính

### Dành cho Sinh viên:
* Đăng ký, đăng nhập tài khoản.
* Xem danh sách thiết bị có trạng thái "Sẵn sàng".
* Tạo phiếu mượn thiết bị và theo dõi trạng thái phiếu duyệt.
* Gửi yêu cầu trả thiết bị sau khi sử dụng.
* Xem lịch sử mượn trả cá nhân.

### Dành cho Admin:
* Quản lý kho thiết bị (Thêm, sửa, xóa, cập nhật tình trạng thiết bị).
* Quản lý phiếu mượn (Duyệt, từ chối kèm lý do).
* Xác nhận trả thiết bị và cập nhật tình trạng thiết bị (Bình thường / Hỏng hóc).
* Quản lý báo hỏng và bảo trì (Ghi nhận chi phí, nhật ký sửa chữa, tự động đưa thiết bị về trạng thái sẵn sàng).
